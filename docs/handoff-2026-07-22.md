## 개발 환경 함정 (둘 다 코드 버그처럼 보인다)

**dev 서버가 떠 있을 때 `npm run build`를 돌리면 `.next`가 깨진다.** 앱이 백지가 되고 `Cannot find module './vendor-chunks/next.js'`가 뜬다. 서버를 먼저 내리거나, 겪었다면 `rm -rf .next` 후 재기동.

**`public/` 아래 이미지를 교체해도 `.next/cache/images`가 예전 최적화 결과를 계속 내려준다.** URL이 그대로라 캐시가 무효화되지 않는다. `curl`로 원본을 받아보면 새 파일이 맞아서 브라우저 캐시 문제로 오해하기 쉽다. `rm -rf .next/cache/images`만 지운다(`.next` 전체를 지우면 위 함정에 걸린다).
