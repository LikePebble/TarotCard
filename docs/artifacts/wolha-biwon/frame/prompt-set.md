# 월하비원 Imagen 프레임 시안 프롬프트 세트

## 공통 편집 기준

- 사용자 제공 이미지는 장식 밀도와 프리미엄 세공 품질의 참고 이미지로만 사용한다.
- `the-high-priestess.webp`는 편집 대상이다. 인물의 얼굴·신체·포즈·손·의상·두루마리와 기둥·석류 장막·초승달·정원·조명을 유지한다.
- 변경 범위는 프레임과 비어 있는 상단 번호판·하단 제목 명패뿐이다.
- 프레임은 중앙 원화의 외곽 약 6% 안에서만 겹치고, 얼굴·손·두루마리·핵심 도상은 가리지 않는다.
- 하단 명패는 불투명 사각형이 아니라 원화가 부드럽게 비치는 반투명 재질과 세공 테두리로 구성한다.
- 이미지 안에는 문자·숫자·로고·워터마크·서명을 생성하지 않는다.
- 납작한 SVG, UI 패널, 두꺼운 바, 유럽식 바로크 복제, 과도한 금색을 피한다.

## 시안별 소재

1. 월광 나전: 먹색 칠기, 나전 매화, 대나무, 창호, 노리개와 골동 금속.
2. 은청 창호: 은세공 창호와 월문, 서리 낀 청회색 유리, 자개 대나무.
3. 청자 달항아리: 청자·백자 유약, 얇은 금선, 매화와 구름, 유백색 반투명 명패.
4. 포도주빛 비단: 와인색 비단·오간자, 매듭과 술, 진주, 한복 깃 형상의 코너.
5. 궁궐 처마: 기와 처마와 목재, 절제된 단청, 현판, 매듭으로 매단 반투명 칠기 명패.
6. 먹빛 석정: 벼루·강돌·연기석, 은입사, 물결과 매죽 부조, 자개 반사.
7. 궁중 병풍: 남색 칠기 병풍, 금속 경첩, 자수 매죽·모란·물결과 투명 비단 패널.
8. 매죽 비대칭: 좌하단 매화와 우상단 대나무, 은빛 이슬, 창호와 노리개로 균형을 잡은 비대칭 구성.
9. 월광 금속: 브러시드 실버·티타늄·스모키 글라스, 창호와 한복 깃을 현대적으로 단순화한 금속 세공.
10. 비원 생장 아치: 매화·대나무·동백 잎·석류 봉오리와 창호 금속이 하나의 생장 구조처럼 결합한 프레임.
