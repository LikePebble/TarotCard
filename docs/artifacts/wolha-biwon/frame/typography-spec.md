# 매죽 비대칭 선택안 — 타이포그래피 적용 규칙

## 기준

- 기준 캔버스: 1200 × 2040 px
- 모든 좌표와 크기는 `design-tokens.json`에만 정의한다.
- 다른 해상도에서는 `renderWidth / 1200` 비율로 위치·크기·그림자를 함께 스케일한다.
- 메이저 아르카나는 상단 중앙에 로마 숫자를 표시한다.
- 마이너 아르카나는 번호 레이어를 렌더링하지 않으며 상단 장식은 그대로 유지한다.
- 카드명은 프레임 이미지에 굽지 않고 런타임 텍스트 레이어로 렌더링한다.

## 고정 좌표

| 영역 | 값 |
|---|---|
| 번호 명패 | x 410, y 24, w 380, h 92 |
| 번호 기준선 | y 80 |
| 하단 명패 | x 215, y 1754, w 770, h 266 |
| 제목 안전영역 | x 325, y 1815, w 550, h 145 |
| 한글 기준선 | y 1900 |
| 영문 기준선 | y 1930 |

## 장문 처리

- 한글 9자 이상: 44px, 13자 이상: 38px
- 영문 22자 이상: 18px, 30자 이상: 16px
- 장문에서도 중앙 앵커와 기준선은 이동하지 않는다.
- 한 줄 말줄임은 사용하지 않는다. 전체 카드명이 보이는 것을 우선한다.
