# 3카드 포지션 시점 정합 + 가독성 교정 설계 — 2026-07-25

## 목적

3카드(과거/현재/미래) 결과에서 읽는 분량의 대부분이 현재 어조라 시점이 어긋난다(포지션 반영은 1문장뿐). 주연 텍스트를 그 시점의 어법으로 세우고, 겸사겸사 읽기 어려운 기존 텍스트를 선별 교정한다. 근거 리서치: `docs/research/2026-07-25-position-based-interpretation.md` — Waite 켈틱 크로스 원문이 자리별 시제 굴절을 명문화("behind him"=과거형/"before him"=미래형), 확인된 타 서비스는 카드×자리 사전 집필이 없어 우리가 앞선 접근.

## 1. 포지션 문단 증축 (468건)

- `ko-positions.ts`(정방향 78×3)·`reversed-positions.ts`(역방향 78×3)를 **1문장 → 2~3문장 문단**으로 재저작.
- 시점 어법 유지·강화: 과거=회고(무엇이 지나갔고 지금의 뿌리가 되었나), 현재=진단(지금 작동하는 힘), 미래=전망(열려 있는 가능성과 준비). 한 카드의 세 문단이 같은 구를 돌려쓰지 않는다.
- 의미 근거: 정방향은 `ko.ts` 정본의 의미 축, 역방향은 `docs/reversed-variants-basis-2026-07-23/positions.json`의 Waite·Mathers 근거 + 방금 재저작된 현행 문장(이미 근거 정합 검수 통과)을 씨앗으로 확장.
- 데이터 구조·키 불변(텍스트만 교체). 소비처 `ReadingResult.tsx`의 인터페이스 불변.

## 2. 3카드 화면 위계 재편 (`ReadingResult.tsx` 3카드 분기만)

```
[포지션] 과거
[카드명]
포지션 문단 (주연 — 증축된 2~3문장, 시점 어법)     ← 기존 1문장 자리 그대로, 본문 승격
─────
"이 카드가 지금 {테마}에 건네는 말"                 ← 테마 라벨 리프레임(텍스트 재작성 없음)
테마 문단 (현행 유지)
▸ 카드 자체의 의미 보기                             ← 접힘 — 무시점 정본 2문단이 여기로
```

- 역방향도 동일 구조(역방향 포지션 문단 주연 → 역방향 테마 리프레임 → 역방향 정본 접힘 → 기존 정방향 접힘 유지).
- **원카드(오늘의 카드)는 변경 없음** — 현재 시점이 맞는 화면.
- day 테마(테마 문단 없음)면 테마 블록 생략(현행과 동일).

## 3. 가독성 교정 (선별)

- **신규 468건 저작 지침에 가독성 규칙 포함**: 문장 40자 내외, 한 문장 한 생각, 은유는 문단에 하나까지, 이중 수식·관념어 연쇄 금지, 일상어 우선. 성찰적 존댓말 톤은 유지하되 "쉽게 읽히는 성찰"이 기준.
- **기존 정본 선별 교정**: `ko.ts`(정방향 78)·`reversed.ts`(역방향 78, ko+en 중 ko만)를 감사해 읽기 어려운 항목만 교정.
  - 선별 기준: ① 60자 이상 문장 ② 은유 2겹 이상 겹침 ③ 관념어 밀도(추상명사 연쇄)로 뜻이 흐려진 문단 ④ 이중 부정.
  - 교정 원칙: 의미·톤 보존, 문장 분할과 쉬운 어휘 치환 위주. 전면 재작성 금지(감사 통과 이력이 있는 텍스트다).
  - 예상 규모: 전체의 10~25% 내외(감사 결과에 따름). en은 이번 범위 외.
- 테마·로어 등 나머지 코퍼스의 가독성은 이번 범위 외(추후 별도 배치).

## 4. 파이프라인 (사용자 지정 유지)

- **저작·교정: Codex 워커** — 잡 분할: ① ko-positions 증축(78×3) ② reversed-positions 증축(78×3) ③ 정본 가독성 감사+교정안(ko.ts) ④ 동(reversed.ts ko). 산출은 `.scratch/position-voice/*.json`, 조립·검증·커밋은 어드바이저.
- **검수: Opus 5** — ① 시점 어법 성립(회고/진단/전망) ② 의미 보존(정본·basis 대비) ③ 가독성 기준 충족 + 교정의 의미 훼손 여부 ④ 톤 유지. 지적 반영 후 재검수.
- UI 재편은 SDD 워커 + 태스크 리뷰 + 브라우저 검증(어드바이저).

## 테스트

- 포지션 형식 테스트 보강: 기존 `reversed-variants.test.ts`의 비어있지 않음 검증 유지 + 증축 후 문장 수(2~4) 검증을 정·역 포지션 모두에 추가(신규 `positions` 형식 테스트).
- 정본 교정: 기존 형식 유지(문단 수 2, `\n\n`) — `ko.ts` 교정이 구조를 깨지 않는지 타입·기존 테스트로 확인.
- UI: 3카드 위계 재편 브라우저 실측(3시점 탭, 역방향, day 테마, 접힘 동작). 원카드 회귀 없음.
- 실행: `./node_modules/.bin/vitest run` / `tsc --noEmit`, dev 서버 중 `npm run build` 금지.
