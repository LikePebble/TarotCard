# 카드 아트 제작 규격 (Card Art Specification)

78장 캐릭터 카드 아트 제작을 위한 공통 규격이다. 카드별 장면·상징 명세는 `data/art/*.json` (사람이 읽는 문서: `docs/card-art-prompts.md`) 를 따른다.

## 1. 파일 규격

| 항목 | 규격 |
|---|---|
| **비율** | **4:7 고정** (앱 전체가 `--card-ratio: 4/7`로 렌더링, `object-fit: cover`) |
| 마스터 원본 | 1600 × 2800 px 이상, 무손실(PSD/PNG) — 인쇄·마케팅 재활용 대비 |
| 서비스 배포본 | 800 × 1400 px, WebP(권장) 또는 JPEG 품질 85 |
| 색 공간 | sRGB |
| 파일명 | `images/{card-id}.webp` — card-id는 `data/cards/*.json`의 `id` 필드와 정확히 일치 (예: `the-fool`, `ace-of-wands`, `queen-of-swords`) |
| 용량 목표 | 배포본 장당 150KB 이하 (78장 총 ~10MB 이내) |

## 2. 세이프존 (역방향 대응 — 중요)

역방향 카드는 **이미지를 180° 회전**해서 표시한다. 따라서:

- **핵심 심볼과 캐릭터는 중앙 60% 영역** 안에 배치 (상하 각 20%는 배경·분위기 요소만)
- **문자·숫자·카드명은 아트에 넣지 않는다** — 카드명은 UI가 렌더링 (다국어 대응·역방향 가독성 문제)
- 상하가 뒤집혀도 "망가져 보이지 않는" 구도를 지향 (완전 대칭일 필요는 없음 — 뒤집힌 게 보이는 건 의도된 연출)

```
┌─────────────┐
│  배경/분위기   │ ← 상단 20%: 하늘·빛 등
├─────────────┤
│             │
│  핵심 심볼    │ ← 중앙 60%: 캐릭터·필수 상징
│  + 캐릭터    │
│             │
├─────────────┤
│  배경/분위기   │ ← 하단 20%: 지면·물 등
└─────────────┘
```

## 3. 카드 뒷면 (별도 1종)

- 동일 규격 (4:7, 800×1400)
- **반드시 180° 회전 대칭 디자인** — 뒷면만 보고 카드의 정/역 방향을 유추할 수 없어야 함 (뽑기 공정성)
- 파일명: `images/card-back.webp`
- 현재는 CSS 그라디언트가 임시 뒷면 — 교체 시 `public/styles/reading.css`의 `.tarot-card-back` / `.f-card` 배경만 수정

## 4. 스타일 가이드 (캐릭터 컨셉 확정 시 채울 것)

아래 항목은 캐릭터 디자인 방향이 확정되면 이 문서에 추가한다. 카드별 명세(`data/art/`)는 **스타일 중립**으로 작성되어 있어 어떤 스타일이 와도 재사용 가능하다.

- [ ] 캐릭터 세계관·종족·등장인물 로스터 (78장에 걸쳐 재등장하는 캐릭터 매핑)
- [ ] 렌더 스타일 (셀 셰이딩 / 수채 / 플랫 등) 및 선 굵기·질감
- [ ] 공통 팔레트 (수트별 키 컬러: 완드=불/적황, 컵=물/청록, 소드=바람/한랭, 펜타클=흙/녹갈 권장)
- [ ] 테두리·프레임 유무 및 규격
- [ ] AI 생성 파이프라인 사용 시: 스타일 LoRA/레퍼런스 시트, `{STYLE}` 치환 문자열 확정

## 5. 카드별 명세 데이터 (`data/art/`)

78장 각각에 대해 다음 스키마로 정의되어 있다:

```json
{
  "the-fool": {
    "title": { "ko": "바보", "en": "The Fool" },
    "essence": "카드의 본질 한 줄",
    "scene": "캐릭터가 무엇을 하고 있는지 — 구도가 그려지는 한국어 장면 묘사 2~3문장",
    "symbols": ["필수 상징 목록 — 이 요소들은 반드시 그림에 포함"],
    "mood": "감정·조명·시간대",
    "palette": "권장 색 방향 (스타일 확정 전 가이드)",
    "promptEn": "AI 이미지 생성용 영문 프롬프트. {STYLE} 플레이스홀더 포함, 스타일 중립"
  }
}
```

- `symbols`는 **전통 상징 중 해석 정확성에 필수적인 것만** 추린 목록이다. 캐릭터·배경 연출은 자유지만 이 요소들이 빠지면 카드 의미가 훼손된다.
- `promptEn` 사용법: `{STYLE}`을 확정된 스타일 문자열(예: `"soft watercolor, storybook children's illustration"`)로 치환해 이미지 생성 모델에 입력. 네거티브 프롬프트에 `text, letters, numbers, watermark, borders` 권장 (§2 문자 금지 규칙).

## 6. 납품 체크리스트 (장당)

- [ ] 4:7 비율, 800×1400 WebP, sRGB, 150KB 이하
- [ ] 파일명이 card-id와 일치
- [ ] `symbols` 목록의 요소가 모두 포함됨
- [ ] 문자·숫자 없음
- [ ] 핵심 요소가 중앙 60% 세이프존 안
- [ ] 180° 회전해서 봐도 파탄 없는 구도
- [ ] (뒷면) 회전 대칭 확인

## 7. 적용 방법

1. `images/`에 새 파일 배치 (`{card-id}.webp`)
2. `data/cards/*.json`의 `image`·`media[].url`을 `/tarotdeck/{card-id}.webp`로 갱신 (스크립트 일괄 처리 가능)
3. 서버 재시작 없이 정적 서빙으로 즉시 반영 — 코드 수정 불필요
