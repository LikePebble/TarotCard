# IP 기반 영문 현지화 외부 검증 계획서

## 목적과 판정 기준

같은 URL에서 Vercel 국가 코드가 `KR`이면 한국어, 그 밖의 국가 및 국가 코드가
없는 요청이면 영어가 노출되는지 검증한다. 언어 선택 UI, 쿠키 고정, `/en` 등의
언어 경로는 없어야 한다. 카드 이미지에 구워진 한글은 앱 결함으로 판정하지 않고
별도 아트 파이프라인 이슈로 기록한다.

각 항목은 **통과 / 실패 / 보류**와 증거(요청 헤더, URL, 스크린샷, 응답 헤더)를
남긴다. 서비스 내용·계정·결제 데이터를 생성하거나 변경하지 않는다.

## 준비

1. Vercel Preview 배포 URL과 배포 커밋 SHA를 기록한다.
2. 다음 세 요청 조건을 준비한다. Preview에서 국가 헤더를 직접 주입할 수 없다면
   Vercel의 지역 테스트 환경 또는 각각 한국/비한국 egress를 사용한다.

   | 조건 | 기대 locale |
   | --- | --- |
   | `X-Vercel-IP-Country: KR` | `ko` |
   | `X-Vercel-IP-Country: US` | `en` |
   | 국가 헤더 없음 | `en` |

3. 비로그인 브라우저 프로필 하나와 테스트 계정 하나를 사용한다. 이미 존재하는
   일기·리딩을 지우지 않는다.

## 국가별 HTTP·SEO 확인

각 조건에서 `/`, `/reading`, `/collection`, `/terms`, `/privacy`를 확인한다.

- HTML `lang`이 기대 locale과 일치한다.
- `<title>`, description, Open Graph, Twitter 제목·설명이 해당 언어다.
- 한국 요청은 한국어 정본을, US와 헤더 없음 요청은 영어 정본을 보인다.
- URL은 언어와 무관하게 동일하며, 언어 토글·언어 설정 쿠키·`/en` 리다이렉트가 없다.
- 동적 요청이 국가 간에 섞여 제공되지 않는지 두 국가를 번갈아 3회씩 새로고침해
  확인한다. 응답의 캐시 제어와 CDN 캐시 상태를 함께 기록한다.

참고: 현재 Next 최종 응답에서는 middleware가 추가한 `Vary:
X-Vercel-IP-Country`가 보존되지 않을 수 있다. 이 경우 Preview 응답이
`no-store`/동적 처리인지, 또는 Vercel 캐시가 국가별로 안전하게 분리되는지를
운영자가 반드시 확인한다. 언어가 섞이면 **출시 차단**이다.

## 화면 검증

US와 헤더 없음 조건에서는 다음을 키보드와 마우스로 모두 점검한다. 화면의 버튼,
레이블, placeholder, 오류·로딩 상태, `aria-label`을 포함해 앱 코드에서 보이는
문구가 영어여야 한다.

1. 홈, 상단/하단 내비게이션, 로그인, 404.
2. 리딩 선택 → 주제 선택 → 카드 뽑기 → 결과, 공유, 카드 상세, 도감 이동.
3. 클래식 및 프리미엄 덱 목록·상세·상품 모달. 프리미엄 아트 속 한글은 캡처만
   남기고 별도 아트 이슈로 분류한다.
4. 로그인 전/후 MY, 계정 동기화·로그아웃, 문의 모달, 일기 목록·달력·상세·빠른 메모.
5. 약관·개인정보처리방침의 제목, 버전, 시행일, 개정 이력, 본문, 상호 링크.

한국 조건에서는 같은 핵심 흐름을 표본으로 다시 확인해 기존 한국어 정본과 기능이
회귀하지 않았는지 확인한다.

## 타로 콘텐츠 표본

영문 결과에서 다음 6개 카드를 각각 정방향과 역방향으로 확인한다:
`the-fool`, `the-lovers`, `ace-of-cups`, `five-of-swords`, `queen-of-wands`,
`ten-of-pentacles`.

- 기본 해석, 5개 주제(종합·연애·관계·일·마음), 3개 포지션(과거·현재·미래)이
  해당 카드·방향에 맞는 영어 문장이다.
- lore의 상징, 이야기, 원소·수비학·점성술 표기가 영어이고 서로 다른 카드의
  일반 문장으로 대체되지 않는다.
- 결과·상세 페이지에서 한국어 해석 접기/펴기나 한국어 fallback이 노출되지 않는다.
- 문장은 단정적 예언이 아니라 성찰적 안내 톤이다.

## 접근성·회귀 확인

- 키보드만으로 내비게이션, 모달 닫기, 리딩 선택, 공유/일기 링크에 도달한다.
- 모달의 닫기 버튼·카드 이미지 대체 텍스트가 선택된 언어다.
- 로그인하지 않은 사용자가 프리미엄 덱이나 개인 기록에 접근할 때 기존 권한 규칙이
  유지된다.
- VPN/로밍으로 국가가 바뀌면 다음 요청부터 언어가 즉시 바뀌는 것이 정상이며,
  사용자 설정으로 고정되지 않아야 한다.

## 결과 보고 형식

각 실패는 `심각도 / 국가 조건 / URL / 재현 단계 / 기대 / 실제 / 스크린샷 또는
헤더 / 카드 아트 여부`를 한 행으로 기록한다. 아래는 출시 차단(P0)이다.

- 국가 조건과 다른 HTML 언어·메타·법적 본문이 제공됨
- 한국어 UI 또는 해석 데이터가 영어 경로에 노출됨(구워진 카드 아트 제외)
- 국가 간 캐시 혼선
- 리딩, 로그인, 컬렉션, 법적 문서를 사용할 수 없게 만드는 기능 회귀

영문 법적 문구의 법적 적정성은 자동 테스트 범위 밖이므로, 운영/법무 검토 결과를
별도 승인으로 첨부한다.
