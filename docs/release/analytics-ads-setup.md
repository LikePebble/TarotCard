바로 동작하도록 이미 붙어 있고, 값이 없으면 아무것도 렌더하지 않는다.

## 1. GA4 — 측정 ID 발급

1. [Google Analytics](https://analytics.google.com) → 관리 → 속성 만들기
2. 속성 이름 `아르카 타로`, 시간대 **대한민국**, 통화 **KRW**
3. 데이터 스트림 → **웹** → URL `https://arca.realm.ai.kr`
4. **측정 ID**(`G-`로 시작)를 복사

### Vercel에 넣기
Vercel 프로젝트 → Settings → Environment Variables

```
NEXT_PUBLIC_GA_ID = G-XXXXXXXXXX
```

Production·Preview 모두에 넣되, **Preview에는 넣지 않는 편**이 낫다. 개발 중
트래픽이 실제 지표에 섞인다.

> 넣은 뒤 **재배포해야 반영된다.** `NEXT_PUBLIC_` 변수는 빌드 타임에 구워진다.

## 2. Google Search Console

**GA4를 먼저 붙인 뒤** 진행한다. GA 연동으로 소유 확인하면 별도 태그가 필요 없다.

1. [Search Console](https://search.google.com/search-console) → 속성 추가
2. **URL 접두어** 선택 → `https://arca.realm.ai.kr`
   - 도메인 속성(`realm.ai.kr`)을 고르면 DNS TXT가 필요하고 다른 서브도메인
     데이터까지 섞인다. 아르카만 볼 것이면 URL 접두어가 맞다.
3. 소유 확인 방법에서 **Google 애널리틱스** 선택
   - GA4 속성에 **편집 권한**이 있어야 한다. 같은 계정이면 자동
4. 확인 후 → 색인 생성 → **Sitemaps** → `sitemap.xml` 제출

### 이후 볼 것
**페이지 리포트에서 86개 URL이 "검색됨 → 색인 생성됨"으로 넘어가는지**가 지난
SEO 작업의 유일한 성공 지표다. 첫 색인까지 며칠에서 몇 주 걸린다.

## 3. AdSense

### 3-1. 출시 기념 프로모션 켜기

**로그인한 사용자에게 프리미엄 덱을 드리는 한정 기간 프로모션**이다. 환경변수
이름은 구현 확정 후 이 문서에 채운다.

프로모션을 켜면 로그인 사용자에게 프리미엄 덱이 열리고, 게스트에게는 로그인
유인 문구가 노출된다. 마케팅 감사가 최대 공백으로 꼽은 "가치를 얻은 직후 계정으로
전환시키는 장치"를 메우는 것이 본래 목적이다.

> **출시 때 반드시 끌 것.** 켜진 채로 유료 판매를 시작하면 "무료였는데 유료가
> 됐다"는 소비자 오인이 된다.

#### ⚠️ AdSense 심사에는 도움이 되지 않는다

처음에는 이 해금이 심사자에게 콘텐츠를 열어 줄 것으로 봤으나 **사실이 아니다.**
`src/lib/collection-access.ts:10`이 로그인 여부를 먼저 본다.

```ts
if (!signedIn) return { owns: false, encounters: new Set() };
```

AdSense 심사자와 크롤러는 보통 로그인하지 않으므로, 소유 판정과 무관하게 도감은
잠긴 채로 보인다. 프로덕션 실측으로도 확인했다 — 비로그인 상태의
`/collection/classic`은 카드 상세 링크가 **0개**다.

**심사자가 실제로 볼 수 있는 것**은 sitemap에 올라가 있는 카드 상세 78페이지
(각 1,300자 내외)와 홈·컬렉션 목록이다. 심사 통과 가능성을 높이려면 프로모션이
아니라 **카드 상세 본문을 두껍게 하는 작업**(마케팅 감사 Phase 2)이 필요하다.

### 3-2. 신청

1. [AdSense](https://adsense.google.com) 가입 — 사이트 `arca.realm.ai.kr`
2. **게시자 ID**(`ca-pub-`로 시작)를 복사해 Vercel에 넣고 재배포

```
NEXT_PUBLIC_ADSENSE_CLIENT = ca-pub-XXXXXXXXXXXXXXXX
```

넣고 배포하면 자동으로 처리되는 것:
- `<meta name="google-adsense-account">` — 사이트 소유 확인용
- 광고 라이브러리 스크립트
- `https://arca.realm.ai.kr/ads.txt` — 게시자 ID로 자동 생성 (값이 없으면 404)

3. AdSense 콘솔에서 **검토 요청**

### 3-3. 승인 대기 중 해둘 것 — EEA 동의

AdSense는 EEA·영국·스위스 트래픽에 **Google 인증 CMP**를 요구한다. 한국 서비스라도
그쪽 방문자가 오면 적용된다.

AdSense 콘솔 → **개인정보 보호 및 메시지** → **GDPR 메시지** 만들기.
Google 자체 인증 CMP라 무료이고, 별도 CMP를 붙일 필요가 없다.

### 3-4. 승인 후 — 개발 작업이 남아 있다

승인이 나면 알려줄 것. 코드 쪽에 다음이 남아 있다.

- 광고 슬롯 **배치** (컴포넌트는 준비돼 있으나 어디에도 놓지 않았다)
- 개인정보처리방침의 "도입 예정" 문구를 실제 적용으로 개정 (**버전 0.9 → 1.0**)

**배치 원칙** — 넣어도 되는 곳과 안 되는 곳이 분명하다.

- ✅ 카드 상세 하단, 컬렉션 목록, 일기 목록 — 본문이 길고 탐색 맥락
- ❌ **뽑기 애니메이션 중, 결과 리빌 직후** — 이 제품에서 가장 몰입도가 높은
  순간이다. 여기 광고를 넣으면 브랜드 카피가 무너지고 프리미엄 덱의 가격
  정당성도 함께 깎인다

## 4. 권장 순서

```
① GA4 ID 발급 → Vercel 주입 → 재배포
② Search Console 소유 확인 → sitemap 제출
③ 베타 해금 켜기 → 재배포
④ AdSense 신청 → 게시자 ID 주입 → 재배포 → 검토 요청
⑤ (심사 대기 중) GDPR 메시지 설정
⑥ 승인 후: 광고 배치 + 방침 개정
```

**②와 ④ 사이에 2~3주 두는 것을 권한다.** 지금 지표가 0이라 기준선이 없다. 광고를
켠 뒤 이탈률이 올라가도 광고 탓인지 티켓제 탓인지 구분할 수 없다.

## 5. 아직 남아 있는 별건

- `src/data/legal/operator.ts`의 운영자 정보가 **플레이스홀더**다. 출시 전 교체 필요
- Vercel의 `NEXT_PUBLIC_ENABLE_RELEASE_TEST_TOOLS` 실값 확인 — `true`면 누구나
  프리미엄 덱을 지급받을 수 있다
- 유료 판매를 시작하려면 **사업자등록(간이과세자)** 이 필요하다. 간이과세자면
  통신판매업 신고는 면제된다
