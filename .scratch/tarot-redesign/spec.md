# TarotCard 리디자인 스펙

2026-07-18 그릴링 세션에서 합의된 내용. 리디자인 전 서비스 페이지, 플로우, 향후 확장 요소 정리.

## 정체성

소비자용 한국어 타로 리딩 서비스. 기존 "개발자용 API 데모"에서 방향 전환.
카드 수집(컬렉션)이 핵심 리텐션 축이며, 수익 모델은 테마 카드덱 판매.

## 페이지 & 플로우

```
/                랜딩: 분위기 히어로, 리딩 시작 CTA
/reading         리딩 선택: 오늘의 카드(1장) | 과거·현재·미래(3장)
/reading/focus   질문 영역 선택: 사랑 / 일 / 나 자신 / 오늘 (라벨링용)
/reading/draw    카드 스프레드에서 직접 선택 -> 플립 공개 -> 해석
/collection      수집 현황: 78장 진행도, 아르카나별 그룹, 미수집은 카드백+이름
/collection/:slug 카드 상세: 아트, 해석 전문, 수집 이력 (리딩 결과에서 진입)
```

리딩 플로우: 랜딩 -> 리딩 방식 선택 -> 질문 영역 선택 -> 카드 선택(스프레드에서 유저가 직접 고름) -> 플립 공개 + 해석 -> 컬렉션 수집.

## 3장 리딩 시나리오 (2026-07-18 컨펌)

1. `/reading`에서 "과거 · 현재 · 미래" 선택, `/reading/focus`에서 질문 영역 선택 (1장과 동일 경로)
2. `/reading/draw`: 화면 상단에 과거/현재/미래 빈 슬롯 3개. 부채꼴에서 한 장씩 세 번 선택
   - 고른 카드는 뒷면 그대로 슬롯으로 이동, 부채꼴에서 제거 (비복원 추출, 중복 없음)
   - 남은 장수 안내 ("한 장 더 고르세요")
3. 세 장이 모이면 과거 -> 현재 -> 미래 순서로 순차 플립 (자동, reduced-motion 시 즉시 표시)
4. 결과: 세로 스크롤 한 페이지. 카드 3장 미니 로우 + 포지션별 섹션(포지션 라벨, 카드, 카드명, 해석 전문)
   - 해석은 카드당 1개 데이터를 그대로 사용. 포지션별 맞춤 해석은 로드맵 "해석 심화"에서 확장
   - 세 카드 종합 총평은 정적 콘텐츠로 불가, 향후 AI 해석으로 로드맵 검토
5. 세 장 모두 컬렉션에 수집 ("3장이 컬렉션에 추가되었습니다 n / 78")

## 핵심 결정

- **언어**: 한국어 UI + 해석 한국어 재작성. 영어 원문 보존 (데이터 ko/en 이중화). 카드명 병기: "바보 The Fool"
- **리딩 스코프**: 1장(오늘의 카드) + 3장 스프레드(과거/현재/미래). 서버(또는 앱 로직)에 스프레드 지원 추가
- **질문 영역**: 라벨링/맥락 제시용. 영역별 맞춤 해석은 로드맵 항목 (데이터가 카드당 1개뿐)
- **컬렉션**: 뽑은 카드가 수집됨. 미수집 카드는 카드백 + 이름만 공개 (수집 동기 부여). 진행도 표시 (n / 78)
- **카드 상세**: 독립 페이지 `/collection/:slug`. 해석 전문 + 수집 이력(첫 수집일, 뽑은 횟수)
- **저장소**: 런칭은 localStorage (수집 상태, 리딩 이력). 계정 도입 시 마이그레이션 경로를 데이터 스키마에 미리 반영 (버전 필드, export 가능한 구조)
- **덱 체제**: deck 개념 도입. 기본덱 1종(현행 라이더-웨이트 이미지, 무료) + 유료 덱 2종 판매 예정. 런칭은 기본덱만 활성화, 데이터 모델은 멀티덱 지원

## 기술 스택

- Next.js (App Router) + Tailwind v4 + Motion 단일 앱
- Express 폐지. 카드 데이터는 TS 모듈로 이전
- 기존 API 호환 라우트 보존: `GET /cards`, `GET /cards/onecard`, `/tarotdeck/:image`
- 향후 계정/결제는 Supabase, 배포는 Vercel 전제

## 해석 확장 (2026-07-19 확정, 로드맵 3번을 당김)

- 질문 테마 확정: 오늘의 카드 = 사랑/일/나 자신/건강/금전/오늘 하루, 3장 = 사랑/일/나 자신/건강/금전 (오늘 하루 제외)
- 테마별 맞춤 문단: 카드당 5테마(사랑/일/나 자신/건강/금전) x 78장 = 390문단. 오늘 하루는 기본 해석만 사용
- 3장 포지션별 문장: 카드당 과거/현재/미래 각 1문장 x 78장 = 234문장
- 표시: 리딩 결과에서 기본 해석 + 선택 테마 문단(1장), 포지션 문장 + 기본 해석 + 테마 문단(3장). 컬렉션 상세는 기본 해석 유지
- 건강 테마는 웰니스 톤(의학적 단정 금지), 금전 테마는 태도/흐름 톤(투자 조언 금지)
- 데이터: focus는 id(love/work/self/health/money/day)로 저장, 라벨 맵 별도. 테마/포지션 콘텐츠는 별도 데이터 파일

## 향후 확장 로드맵

1. **계정 + 수집 마이그레이션**: 로그인 도입, localStorage 수집을 계정으로 이전. 덱 구매의 전제 조건
2. **덱 상점 + 결제**: 유료 덱 2종 판매, 구매한 덱으로 카드 아트 전환
3. **해석 심화**: 역방향 카드 의미, 질문 영역별(사랑/일/나/오늘) 맞춤 해석 콘텐츠
4. **공유 + 리텐션**: 리딩 결과 공유 이미지/URL, 오늘의 카드 알림 등 재방문 유도
